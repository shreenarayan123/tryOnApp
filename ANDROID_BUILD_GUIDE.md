# TrySnap – Android Build Guide (Expo Bare Workflow)

## Project Setup
This project is now configured for **Expo Bare Workflow** with Android-only support. It uses:
- **Expo SDK 51** with React Native 0.74.5
- **EAS Build** for generating APKs
- **Metro** bundler (preconfigured for Expo)

## Prerequisites
1. **Node.js** ≥ 18
2. **npm** or **yarn**
3. **EAS CLI** (installed as dev dependency)
4. **Expo Account** (free tier works for dev/preview builds)

## Initial Setup

### 1. Install Dependencies
```bash
npm install
```

The project should now install cleanly without peer dependency conflicts.

### 2. Start Metro Bundler (Development)
```bash
npm run start
```

This starts the Metro bundler on port 8081. Keep this running while developing.

## Building with EAS

### 1. Login to Expo
```bash
npx eas login
```

If you don't have an Expo account, create one free at [expo.io](https://expo.io).

### 2. Build APK for Development/Preview
For testing on a physical device or emulator:

```bash
npx eas build -p android --profile=development
```

This generates an internal APK (faster, not for Play Store distribution).

### 3. Build APK for Production
For Play Store submission or production distribution:

```bash
npx eas build -p android --profile=production
```

This generates an app-bundle (.aab), which is the required format for Google Play Store. To get a standalone APK instead:

```bash
npx eas build -p android --profile=preview
```

## Build Profiles (eas.json)

| Profile     | Output Format | Use Case |
|-------------|---------------|----------|
| `development` | APK | Internal testing, development |
| `preview`     | APK | QA testing, staging builds |
| `production`  | AAB | Google Play Store release |

## Monitoring Builds
Monitor build progress in the terminal or check status on [expo.dev](https://expo.dev).

Once built, you'll receive a download link for the APK.

## Running on Device

### Android Emulator
```bash
adb install path/to/app.apk
```

### Physical Device (via USB)
1. Enable Developer Mode and USB Debugging
2. Connect device via USB
3. Run: `adb install path/to/app.apk`

## Troubleshooting

### Metro Won't Start
- Clear cache: `npm start -- --reset-cache`
- Check Node version: `node --version` (should be ≥ 18)

### EAS Build Fails
- Ensure `.gitignore` includes `android/`, `ios/`, and other native dirs
- Check build logs in the Expo dashboard

### APK Won't Install
- Verify minimum Android API level (set in app.json)
- Check that the device architecture matches the build (arm64-v8a recommended)

